## Как это работает

Модель у бойцов одинаковая, но каждый игрок задаёт ей свой промпт со стратегией. Потом бойцы одновременно выбирают ходы и сражаются, а мы смотрим, чья стратегия сработала лучше.

На каждом ходу движок формирует наблюдение и список допустимых команд. Codex выбирает одну команду в JSON; движок проверяет её и рассчитывает перемещение, урон, энергию и очки. Промпт влияет на выбор тактики, но не меняет правила. MCP для управления бойцами не используется.

## Запуск на своём компьютере

Нужны [Node.js](https://nodejs.org/) 22 или новее и `npm`. Установка npm-пакетов не требуется.

```sh
git clone https://github.com/dapi/promptcore-arena.git
cd promptcore-arena
npm start
```

Если репозиторий уже скачан, открой терминал в его каталоге и выполни `npm start`. Игра откроется в браузере; локальный адрес также появится в терминале. Для остановки нажми `Ctrl+C`.

Для боя с LLM нужен установленный и авторизованный [Codex CLI](https://developers.openai.com/codex/cli). Проверить вход можно командой `codex login status`. Без Codex выбери в игре **«Тренировка»**: встроенные боты работают локально, но текст промптов не влияет на их действия.

## Как играть

1. Задай бойцам имена и напиши два промпта со стратегиями.
2. Выбери модель и уровень **Reasoning**, затем нажми **«Запустить бой»**. Список моделей и доступных уровней приложение получает из Codex при старте. Настройки общие для обоих бойцов. По умолчанию — GPT-6-Luna и низкий reasoning, если эта модель доступна в Codex.
3. Смотри бой по ходам: карта, действия, здоровье, энергия и события показаны на экране. Во время ожидания бойцы «думают» прямо на поле; видны таймер и поступающие ответы Codex.
4. После боя открой **«Разбор»**: попадания, контроль зоны, ошибки, столкновения и ожидания вне зоны. Клик по ключевому моменту открывает этот ход в повторе.
5. Измени стратегию и запусти новый бой или серию из четырёх боёв: две карты, на каждой — обмен стартами. В итогах серии раскрывается сравнение стратегий.

Первоначальные аватары назначаются случайно. Нажми на аватар в карточке, чтобы сменить его: на поле он изменится сразу, в том числе во время боя. Цвета закреплены: голубой и фиолетовый. Клик по полю стратегии открывает большой редактор: обычный крупный шрифт, сохранение по кнопке или Ctrl/⌘+Enter. Escape и «Отмена» оставляют исходный текст. После старта промпты фиксируются для этого боя; редактор позволяет их удобно читать. Кнопка «Изменить для нового боя» открывает новый черновик, сохраняя старый повтор.

Настройки карты открываются по её названию в шапке поля: код карты, генерация новой карты и обмен стартами. После боя итоговая таблица показывает здоровье, контроль зоны и собранную энергию обоих бойцов.

Во время боя показывается текущий ход. Полоса повтора появляется после завершения или остановки боя: пауза, перемотка и скорость управляют просмотром записи. Карта и сообщения показывают выбранный ход. Кнопки **«Вся арена / A / B»** переключают обзор и видимость данных соперника.

Бой проходит на карте 12 × 12. Каждый агент видит лишь часть карты и за ход выбирает одно действие: движение, сканирование, атаку, ловушку, защиту или ожидание. Движение бесплатное; батарейка подбирается при входе и даёт до 4 энергии. Автозаряда нет, новые батарейки появляются каждые 6 ходов. Матч длится до уничтожения бойца либо до 40-го хода. Зона контроля меняется каждые 8 ходов; следующее место заранее отмечено пунктиром. Если внутри оба бойца, очков не получает никто. Полные [правила боя](docs/rules.md) описаны отдельно.

Стартовые стратегии различаются: тактик перехватывает зоны и бережёт здоровье, охотник преследует противника. Звуки боя включаются после первого действия в интерфейсе. Кнопка «Включить звук» под картой запускает короткий проверочный сигнал; «Звук» выключает эффекты. Настройка «Без звука» сохраняется после обновления страницы.

Строка **«Токены»** под журналом показывает фактический расход Codex. Внутри — вход, кэш, выход и reasoning по каждому бойцу, а также расход выбранного хода. Сумма серии видна в её итогах. Если CLI не сообщил расход, это отмечается как отсутствие данных; стоимость в деньгах пока не рассчитывается.

Матчи и повторы сохраняются на этом компьютере в `.arena/matches/` и доступны во вкладке **«История боёв»**. Новые бои используют правила `arena/2`, старые повторы сохраняют `arena/1`. Приложение слушает только локальный адрес; в режиме Codex запросы к модели требуют интернета.
