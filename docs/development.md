# Локальный прототип

## Запуск

Нужен Node.js 22+. Сторонние npm-зависимости отсутствуют.

```sh
git clone https://github.com/dapi/promptcore-arena.git
cd promptcore-arena
npm start
```

Команда запускает приложение на `127.0.0.1` и открывает браузер. Если установлен `port-selector`, используется стабильный порт проекта; иначе свободный порт выбирает система. `npm run dev` запускает без открытия окна. Если приложение уже запущено, открой напечатанный им адрес.

## Codex

Прототип использует установленный и авторизованный Codex CLI, проверенный с версией `0.160.0`. Проверить вход: `codex login status`; при необходимости войти: `codex login`. Установка описана в [документации Codex CLI](https://developers.openai.com/codex/cli).

На каждом ходу приложение одновременно запускает два `codex exec`. Каждый получает только собственное наблюдение, фиксированный промпт и свою краткую память. Ответ ограничен JSON Schema. По умолчанию используется `gpt-6-astra` с reasoning `low`; другую доступную модель можно выбрать переменной `ARENA_CODEX_MODEL` перед запуском приложения. Обоим бойцам всегда назначается одна модель.

Отдельный API-ключ не требуется. Используется текущая авторизация Codex, поэтому расчёт матчей расходует доступные лимиты этой учётной записи. Один матч требует до 80 запросов, серия из четырёх — до 320. Интерфейс и движок локальны, Codex обращается к своей модели через интернет.

Боевые вызовы запускаются с `--ignore-user-config`, `--ignore-rules`, `--ephemeral`, `--sandbox read-only` в отдельных временных пустых каталогах. Shell, MCP из пользовательской конфигурации, плагины, hooks, браузер, computer use, поиск в интернете, skills и делегирование отключены. `project_doc_max_bytes=0` исключает инструкции из AGENTS.md из контекста бойца. Авторизация остаётся штатной; пользовательская конфигурация Codex не изменяется. Каталоги удаляются после ответа. Дополнительная проверка событий CLI останавливает матч при использовании стороннего инструмента.

Один запрос ограничен 90 секундами. Ошибка запуска или модели завершает матч с понятным статусом; рассчитанные ходы остаются доступными. Автоматической подмены на тренировочных ботов нет. Неверное игровое действие означает пропуск хода. Кнопка остановки прерывает оба процесса; незавершённый бой не засчитывается как ничья.

Официальная документация: [неинтерактивный запуск Codex](https://learn.chatgpt.com/docs/non-interactive-mode), [настройки Codex](https://learn.chatgpt.com/docs/config-file/config-reference).

## Интерфейс

- **Арена:** два редактора промптов, выбор Codex или тренировки, seed и обмен стартами, запуск матча и серии из четырёх боёв.
- **Повтор:** Canvas-анимация движения, выстрелов, щита, сканирования и ловушек; здоровье, энергия, контроль, события и комментарии. Пауза, четыре скорости, шаг назад/вперёд, перемотка, обзор всей карты или одного агента. Клавиши: пробел и стрелки, когда фокус вне полей ввода.
- **История:** сохранённые матчи, восстановление промптов и параметров для нового запуска. Каждый реплей можно скачать как JSON.
- **Серия:** две карты, по два матча с обменом стартами. Итоги по победам и ничьим, отдельный просмотр каждого матча.
- **Тренировка:** встроенные боты, без обращений к модели. Свободный текст промпта не управляет тренировочными ботами; интерфейс явно это показывает.

При расчёте через Codex зритель смотрит уже рассчитанные ходы. Если повтор догнал расчёт, он ждёт следующего ответа. Сохранённый бой проигрывается без запросов к модели. `prefers-reduced-motion` отключает анимации перемещений и эффекты.

## Данные и устройство

- `src/engine.mjs` — чистые функции: карта, наблюдение, проверка действий, одновременное разрешение хода.
- `src/agents.mjs` — встроенные боты и адаптер Codex CLI.
- `src/server.mjs` — локальный HTTP API, запуск/отмена, серия и атомарное сохранение реплеев.
- `web/` — игровое приложение, без CDN и внешних шрифтов.
- `site/` — отдельная существующая публичная страница проекта с постановочной демонстрацией.
- `.arena/matches/` — полные JSON-реплеи (промпты, наблюдения, действия, события, кадры и версия модели).
- `.arena/last-prompts.json` — промпты последнего запуска; черновики также сохраняются в localStorage браузера.

`.arena/`, артефакты проверки и временные файлы исключены из Git. Сервер слушает только loopback, проверяет Host/Origin и отдаёт только разрешённые ресурсы из `web/`. Восстановление активного боя после перезапуска не выполняется: уже записанные ходы доступны в истории как незавершённый бой. Одновременно рассчитывается один матч или одна серия.

[Полная спецификация правил](rules.md).

## Проверки

```sh
npm test
npm run check
```

Тесты проверяют симметрию и связность карт, коллизии и обмен позициями, одновременный урон, защиту и ловушки, деление энергии, ограничение видимости, завершение матча, точное воспроизведение, сохранение, серии, ошибки провайдера и отмену.

HTTP-тесты используют отдельную временную папку и свободный локальный порт. Они не вызывают настоящую модель. Браузер проверяется через `playwright-cli` с управляемым headless Chromium; сценарий находится в `scripts/browser-check.js` и требует запущенного приложения. Он создаёт тренировочные матчи в локальной истории. Проверка настоящего Codex выполняется отдельным матчем через интерфейс.

```sh
playwright-cli -s=arena-check open "http://127.0.0.1:$(port-selector --name web)" --config=scripts/playwright.config.json
playwright-cli -s=arena-check run-code --filename=scripts/browser-check.js
playwright-cli -s=arena-check close
```

Снимки экрана сохраняются в `artifacts/` (создать папку перед проверкой).

## Границы прототипа

Баланс пока экспериментальный. Карты симметричны, но разные промпты и недетерминированные ответы модели требуют серии матчей для сравнения. Формат реплея версионирован, миграции между будущими версиями ещё нет. Публикация приложения, аккаунты и доступ по сети относятся к возможному следующему этапу.
