# Ролик для сайта · 2026-10-04

`site/media/arena-demo.mp4`: 30 секунд, 1280 × 720, H.264/AAC, faststart. Записан работающий браузерный интерфейс в Playwright; для кадра скрыты навигация повтора и правая колонка, расширено поле. Из записи обрезана верхняя полоса. Все 40 ходов показываются последовательно по 0,6 секунды; ожидание Codex отсутствует, итог задержан в конце. Аудио записано из Web Audio игры, без сторонней музыки.

Источник — локальный завершённый матч `99a20b40-5b5a-4a8d-9974-78df924d9a90`, `arena/2`, `sector-07`, `gpt-6-luna` / `low`, стандартные промпты. Вектор победил по контролю 18:1; здоровье 7:4, сбор энергии 18:22. Это один реальный матч, а не доказательство превосходства стратегии.

Постер извлечён из ролика; JPG используется в социальном превью, WebP — в плеере. На странице — нативные controls, playsinline и preload=metadata, без автоматического воспроизведения со звуком.

Воспроизведение, перемотка к итогу и отсутствие горизонтального переполнения проверены в headless Chromium на ширинах 360, 390, 820, 1024, 1440, 1800 px. Исходная запись и рабочие сценарии находятся в игнорируемой директории `artifacts/`; личные записи матчей не входят в Pages artifact.
